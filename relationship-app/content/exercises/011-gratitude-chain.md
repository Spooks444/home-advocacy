# Gratitude Chain

## Purpose
Build positive momentum through small acknowledgments.

## Steps
- **Daily**: Each partner writes one gratitude note to the other each evening.
- **Share**: Read one note aloud at breakfast.
- **Archive**: Save notes in a shared place only if both consent to storage.

## Safety Rules
No quid-pro-quo expectations. No scoring.

## Usage
Daily for 21 days, then reassess.
