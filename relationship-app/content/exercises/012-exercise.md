# Exercise 012

## Purpose
Add structured communication practice with safety checks.

## Steps
- **Check-in**: Each partner states current mood in one sentence.
- **Practice**: Use one communication skill from Communication Basics.
- **Reflect**: Name one thing that went well and one thing to adjust.

## Safety Rules
- No cross-examination.
- No interruptions during check-in.

## Usage
Use as a weekly practice module.
