# Safety Scripts

## Pause Phrase
Use a pre-agreed phrase to pause any exercise without penalty.

## Timeout Rule
If tension reaches 7/10 or above, switch to:
- breathing
- water break
- separate space

## Re-entry Rule
Return only when both partners agree to resume.

## Storage Rule
Do not store audio or transcript unless both partners consent and the data stays on-device or in encrypted local storage.
