# Welcome to Relationship App

Use this app for structured communication, reflection, and support. Household profile access controls apply to all routes.

## Household Profiles
Access is token-gated. Do not share tokens. Use the Settings page for privacy and display controls.

## Messaging
Messages are scoped to a thread. No raw identifiers, credentials, or secrets should be included in message bodies.

## Exercises
Start with Communication Basics. Use each exercise only once per day unless stated otherwise.

## Support
If a session becomes overwhelming, use the pause protocol and resume only when both participants agree.
