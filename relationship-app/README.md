# Relationship App

Marriage/relationship support communication module for Home Advocacy.

## Modules
- `client/` — UI, components, static assets
- `server/` — API, auth, messaging, scheduling
- `shared/` — schemas, contracts, privacy rules, validation

## Privacy Rules
- User content stays private unless explicitly shared
- No raw identifiers in logs
- Encryption in transit and at rest
- Access tied to verified household profile only
